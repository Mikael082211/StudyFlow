# StudyFlow – Student Study Planner

## About the Project
StudyFlow is a student study-planning website designed to help students organise tasks, manage their time and plan study sessions.

The prototype was developed as part of a Human-Computer Interaction (HCI) Portfolio of Evidence.

## Features
- **Dashboard:** Provides access to the main sections of the website.
- **My Tasks:** Allows students to add, edit, complete, filter and delete tasks.
- **Study Planner:** Generates and saves suggested study plans based on outstanding tasks.
- **Group Study:** Allows students to create study sessions, add notes and copy session details.
- **Responsive Design:** Supports desktop and mobile screen sizes.
- **Local Storage:** Saves supported information in the browser.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in Google Chrome or Microsoft Edge.
4. Start using StudyFlow.

## Project Files
- `index.html` – Website structure.
- `style.css` – Website design and layout.
- `script.js` – Website functionality.
- `README.md` – Project information.

## Limitations
StudyFlow is a front-end prototype. It does not have a backend database, user accounts or real-time group collaboration. Information is stored locally in the browser.
