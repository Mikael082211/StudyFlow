STUDYFLOW PROTOTYPE — PART 3

FILES
- index.html: page structure and content
- style.css: visual design, responsive layout and keyboard focus styles
- script.js: task, planner and group-study interactions

RUN LOCALLY
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.

FEATURES TO DEMONSTRATE
- Dashboard summaries and task progress
- Add, edit, filter, complete and delete academic tasks
- Generate and clear suggested study sessions
- Record group-study sessions and copy session details to share with classmates
- Responsive layout, labelled form controls, keyboard focus indicators and status messages
- Tasks, study plans and group sessions are saved in local browser storage on the same device

IMPORTANT LIMITATIONS
- This is a front-end educational prototype, not a production application.
- Browser storage is local to the device/browser and is not synchronised between users or devices.
- Group Study supports planning and copying session details; it does not provide live chat, accounts or real-time collaboration.
- The study planner uses simple deadline ordering and available daily study hours. It does not account for class timetables, breaks or all personal constraints.
- Accessibility features are included, but this prototype has not been independently certified as WCAG 2.0 conformant.

PUBLISHING
Upload index.html, style.css and script.js to a GitHub repository. Enable GitHub Pages from Settings > Pages, using the main branch and root folder. After GitHub provides the public URL, open it in a private/incognito browser window to confirm that it is accessible without signing in. Add that URL to the final report.
